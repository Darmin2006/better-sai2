## 1.0功能

### 液化
- 7 种工具：向前推进 / 膨胀 / 收缩 / 顺时针 / 逆时针 / 平滑/ 重建
- 笔刷大小、强度可调整
- 逐笔撤销（最多 12 步），支持ctrl+z撤回
- **放大绘制**：全屏窗口液化模式，可以实现类似于模拟原生笔刷液化效果
> [!WARNING]
> **写回是新建图层，位置有轻微偏移，需要手动对位后 `Ctrl+E` 合并；也无法接管 SAI 的画笔事件（不能像内置工具那样直接用笔刷在画布上液化）。**
- 按下F9可以进入液化状态，按下F10退出，同时确认
- 允许屏幕抓取→可只取画面一小块；支持移动/缩放选区

### 渐变映射
- 等价于 PS/CSP 的渐变映射
- 色标可拖动改位置、双击改颜色、右键删除、点空白处新增


### 缩时摄影
- 每 1/2/5/10 秒抓一帧，静止帧自动跳过
- Windows 自带 Media Foundation 编码 H.264 MP4，**不需下载其他软件**
- 输出到 `sai2.exe` 同目录的 `timelapse\` 子文件夹
- 可收起的置顶小窗，录制中不挡画


## 安装

液化集合工具本体：
1. 把 `build\` 里的三个文件放到一个目录（建议 `sai2.exe` 同目录下的 `saimod\`）
2. 目录里放一个 `sai_path.txt`，写 SAI 主程序的完整路径：

```
D:\PaintTool SAI\sai2.exe
```

3. 双击 `SAI2启动器.exe` —— 会拉起 SAI 并注入，SAI 右侧出现面板

5. 也可以先自己开 SAI，再双击启动器，会补注入。

参考线工具：
1.不需要注入：编译 `build_guides.bat` 得到 `build\SAI参考线.exe`，直接双击运行，
2. 打开 SAI 和文档后点「连接 SAI」即可。

## 已知限制

- 写回是**新建图层**，位置有轻微偏移（SAI 粘贴行为决定），实测比较微妙的有一点点偏移，最好还是手动对位
- 一次只处理**当前选中图层**，不包含下面图层
- 抓图长边上限 **4096**（超过会缩放，写回时再还原）
- 缩时录像长边限制 **1920**
- 修改 DLL 后**必须重启 SAI** 才生效
- 注入行为可能被杀软判为 `Behavior:Win32/DefenseEvasion`，需要自行加排除或放行
