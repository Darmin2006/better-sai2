# 使用说明

## 安装

1. 新建一个目录，例如 `sai2.exe` 同级的 `saimod\`
2. 把 `saimod.dll`、`SAI2启动器.exe`、`sai_inject.exe` 放进去
3. 同目录建 `sai_path.txt`，内容为 SAI 主程序完整路径：

```
D:\PaintTool SAI\sai2.exe
```

> 不写也可以：启动器会默认找自己同目录下的 `sai2.exe`。
> 注意必须是 **64 位**的那个（约 5.4 MB），不要指向 32 位的打包外壳。

## 启动

双击 `SAI2启动器.exe`：

- SAI 没开着 → 拉起 SAI + 注入
- SAI 已开着 → 只补注入

成功后 SAI 右侧出现「SAI 液化 / 渐变映射」面板。**换了 DLL 必须重启 SAI** 才生效。

## 面板

```
① 框选 | ② 剪贴板 | ④ 写回 | ● 缩时      ← 第一排
撤销 | 重置液化 | 放大绘制 | 贴回 SAI       ← 第二排
────────────────────────────────────
模式 [向前推进 ▾]
笔刷 ─────●─────
强度 ───●────────
渐变映射 [紫橙][蓝青][热成像][胶片][蓝黄]
[渐变色标条]
[改颜色] [还原原图]
────────────────────────────────────
           预览区
  [① 记住形变] [② 套用到当前图]  ✓ 已记住 …
```

面板默认贴在 SAI 右侧并跟随移动。**拖走标题栏后停止跟随**，点「贴回 SAI」恢复。

## 液化流程

```
SAI 里选中图层
  → F9（自动抓图 + 开大图窗）
  → 涂
  → F10（弹确认）
  → 「是」写回 SAI
```

写回后是**新图层**，位置可能略有偏移：用移动工具拖回去，然后 `Ctrl+E` 向下合并。

### 大图窗

| 模式 | 触发条件 | 操作 |
|---|---|---|
| 精确覆盖 | 之前用「① 框选」框过，且选区还在 SAI 窗口内 | 滚轮禁用（保持 1:1 对齐），左键涂 |
| 全屏 | 没框选记录 | 滚轮缩放 5%~800%，右键拖动平移 |

`回车 / Esc / 双击` 返回面板。

### 液化工具

| 工具 | 作用 |
|---|---|
| 向前推进 | 沿拖动方向推像素 |
| 膨胀 / 收缩 | 以笔刷为中心放大 / 缩小 |
| 顺时针 / 逆时针 | 旋转像素 |
| 平滑 | 位移场向邻域平均收敛，修锯齿边缘 |
| 重建 | 位移场向 0 收敛，抹掉局部形变 |

## 多图层形变（1.2 新增）

**目标**：线稿层和上色层施加**完全一致**的形变。

```
上色层：Ctrl+A → Ctrl+C → ②剪贴板 → 液化 → ①记住形变 → ④写回
线稿层：Ctrl+A → Ctrl+C → ②剪贴板 → ②套用到当前图 → ④写回
```

- 面板底部会显示 `✓ 已记住 W×H` / `✓ 已套用，可写回`
- 尺寸和记住的不一致时，会**自动把当前图缩放到记住的尺寸**再套用，不会失败
- 要套第三层就重复"线稿层"那一步

> **为什么必须用 ② 剪贴板**：`① 框选` 是从屏幕截的，拿不到图层透明度，
> 而且每次手框会差几像素；`② 剪贴板` 拿的是 SAI 复制到剪贴板的 DIB（带 alpha），
> 整层拷贝，尺寸天然一致。

## 渐变映射

1. 先抓图（F9 或 ② 剪贴板）
2. 点一个预设打底
3. 调色标：拖动改位置 / 双击改色 / 右键删除 / 点空白处新增
4. 「④ 写回」

渐变永远从**抓图时的原图**重算，所以反复调不会累积失真。不满意点「还原原图」。

## 缩时摄影

1. 面板点 **「● 缩时」** 打开小窗
2. 选间隔（1/2/5/10 秒）
3. 点 **「● 开始录制」**
4. 画完点 **「■ 停止并保存」**

输出：`sai2.exe` 同目录的 `timelapse\timelapse_YYYYMMDD_HHMMSS.mp4`

- 格式：H.264 / MP4（Media Foundation 编码）
- 长边 1920，静止帧自动跳过
- 抓帧范围：优先用「① 框选」的区域，否则取最大的可见子窗口

## 参考线工具（1.2 新增）

独立程序 `SAI参考线.exe`，**不注入、不修改 SAI**。

1. 打开 SAI 并打开文档
2. 双击 `SAI参考线.exe`（SAI 是管理员启动的话，它也要以管理员身份运行）
3. 点「**连接 SAI**」，状态栏显示：`画布 W×H px (… mm) 缩放% 光标 x,y`
4. 左上角选单位：**像素 px** / **毫米 mm**；毫米需要填 **DPI**（= 新建画布时的分辨率）
   - 换算式：`px = mm ÷ 25.4 × DPI`
5. 输入数值 → **添加竖线 / 添加横线**
6. 其他：
   - 「取鼠标位置」把光标位置填进输入框
   - 双击列表某项把数值回填
   - 勾「拖动模式」可直接在画布上拖线（拖时 SAI 收不到点击，用完记得取消）
   - 状态栏的光标坐标可当**精确取点工具**

> 参考线只是视觉辅助，**不会吸附**（SAI 本身没有吸附机制）；
> 画布旋转时位置会不准（目前只支持未旋转）。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `F9` | 进入液化 |
| `F10` | 退出液化 + 确认 |
| `Ctrl+Alt+G` | 抓图 |
| `Ctrl+Alt+A` | 写回 |
| `Ctrl+Alt+Z` | 撤销一笔 |

面板/预览区有焦点时，普通 `Ctrl+Z` 也能撤销。

## 排错

日志固定在 **DLL 同目录的 `saimod.log`**；参考线的日志是同目录 `saiguides.log`。

| 现象 | 处理 |
|---|---|
| 双击启动器没反应 | 可能被杀软隔离，检查 Defender 隔离区 |
| 面板没出现 | 看 `saimod.log` 有没有 `install hook` / `g_sai=` 行 |
| 抓图全黑 | 该版本 SAI 用了 GPU 渲染，见 README「已知限制」；改用 ② 剪贴板 |
| 写回大小不对 | 画布超过 4096，被缩放后又还原，属正常；若每次都小一圈，检查面板高度是否为 720 |
| 套用形变没反应 | 先 ① 记住形变，再 ② 套用；且必须先用 ② 剪贴板抓过图 |
| 参考线连不上 SAI | 确认已打开文档；SAI 是管理员启动的话参考线也要管理员运行 |
| 热键没反应 | F9/F10 被其它软件占用 |
